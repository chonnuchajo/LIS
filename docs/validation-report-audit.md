## ประเด็นจากต้นฉบับที่ต้องไม่คัดลอกโดยไม่มีการตรวจ

1. หน้า 16 ใช้ Actual 0.104, 0.261, 0.522, 0.783, 1.044 mg/mL ไม่ใช่ Target 0.10–1.00 จึงต้องบันทึกสองค่าแยกกัน
2. หน้า 22: 54.25 × 0.927 / 25 = 2.01159 mg/mL และ 250/1000 เท่ากับ 0.5028975 mg/mL ต้องเก็บทศนิยมเต็ม
3. หน้า 17: คำนวณ Sample SD และ RSD ซ้ำแล้วตรงกับตารางสำหรับข้อมูลที่พิมพ์อยู่
4. หน้า 18–19: RSD 0.70, 0.87, 0.72% เป็น RSD ของค่าเฉลี่ยรายวัน ไม่ใช่ความแปรปรวนรวมของผลรายตัวอย่าง ต้องใช้ข้อมูลดิบรายวันสำหรับ ANOVA
5. ค่า Horwitz 8, 6.28, 5.66 ในรายงานไม่มีนิยามฐาน C ครบถ้วน ห้ามนำ mg/mL ไปแทน mass fraction อัตโนมัติ
6. CIPAC 3807 ระบุ repeatability factor 0.67 แต่รายงานให้เกณฑ์อื่นด้วย ต้องแสดงชื่อสูตรและเกณฑ์ที่เลือก ไม่อ้างว่าค่าเริ่มต้นทั้งหมดตรง CIPAC
7. หน้า 21 Sample 1: Area 134.770 เมื่อใช้สมการหน้า 16 ให้ประมาณ 0.56368 mg/mL ต่างจาก 0.5034 ในตาราง อาจใช้คนละ Calibration จึงต้องเชื่อม ID ของแต่ละชุด
8. ผล %w/w ห้ามเทียบเกณฑ์ %w/v โดยไม่มีค่าความหนาแน่น/ฐานการแปลงหน่วย
9. หน้า 22 Matrix spike ใช้ 0.25 เป็นสารเดิมจากตัวอย่าง ต้องแยกค่าฉลากจากผลวัด unspiked และแก้ dilution ให้ตรงกัน
10. Matrix Blank 4 µL ใน Accuracy กับ 750 µL ใน Standard Check ต่างกันมาก ต้องบันทึกตามการเตรียมจริงและทบทวน
11. เกณฑ์ Specificity ไม่พบพีคกับ ≤0.5% ปรากฏต่างหัวข้อ ต้องให้เลือก decision rule อย่างชัดเจน
12. ระดับต่ำสุดถูกเรียก LOQ แต่ไม่มีหลักฐานการประเมิน LOQ ครบในตารางที่อ่าน ห้ามยืนยันว่าเป็น LOQ เพียงเพราะเป็นระดับต่ำสุด
13. หน้าสุดท้าย 24/23 และข้อความสรุปซ้ำ ต้องสร้างเลขหน้าและผลสรุปจากข้อมูลเดียวกัน
