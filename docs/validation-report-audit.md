## ประเด็นจากต้นฉบับที่ต้องไม่คัดลอกโดยไม่มีการตรวจ

1. หน้า 16 ใช้ Actual 0.104, 0.261, 0.522, 0.783, 1.044 mg/mL ไม่ใช่ Target 0.10–1.00 จึงต้องบันทึกสองค่าแยกกัน
2. หน้า 22: 54.25 × 0.927 / 25 = 2.01159 mg/mL และ 250/1000 เท่ากับ 0.5028975 mg/mL ต้องเก็บทศนิยมเต็ม
3. หน้า 17: คำนวณ Sample SD และ RSD ซ้ำแล้วตรงกับตารางสำหรับข้อมูลที่พิมพ์อยู่
4. หน้า 18–19: RSD 0.70, 0.87, 0.72% เป็น RSD ของค่าเฉลี่ยรายวัน ไม่ใช่ความแปรปรวนรวมของผลรายตัวอย่าง ต้องใช้ข้อมูลดิบรายวันสำหรับ ANOVA
5. ค่า Horwitz 8, 6.28, 5.66 ในรายงานไม่มีนิยามฐาน C ครบถ้วน ห้ามนำ mg/mL ไปแทน mass fraction อัตโนมัติ
6. CIPAC 3807 ระบุ repeatability factor 0.67 แต่รายงานให้เกณฑ์อื่นด้วย ต้องแสดงชื่อสูตรและเกณฑ์ที่เลือก ไม่อ้างว่าค่าเริ่มต้นทั้งหมดตรง CIPAC
7. หน้า 21 Sample 1: Area 134.770 เมื่อใช้สมการหน้า 16 ให้ประมาณ 0.56368 mg/mL ต่างจาก 0.5034 ในตาราง อาจใช้คนละ Calibration จึงต้องเชื่อม ID ของแต่ละชุด
8. ผล %w/w ห้ามเทียบเกณฑ์ %w/v โดยไม่มีค่าความหนาแน่น/ฐานการแปลงหน่วย
9. หน้า 22 Matrix spike ใช้ 0.25 เป็นสารเดิมจากตัวอย่าง ต้องแยกค่าฉลากจากผลวัด unspiked และแก้ dilution ให้ตรงกัน
10. Matrix Blank 4 µL ใน Accuracy กับ 750 µL ใน Standard Check ต่างกันมาก ต้องบันทึกตามการเตรียมจริงและทบทวน
11. เกณฑ์ Specificity ไม่พบพีคกับ ≤0.5% ปรากฏต่างหัวข้อ ต้องให้เลือก decision rule อย่างชัดเจน
12. ระดับต่ำสุดถูกเรียก LOQ แต่ไม่มีหลักฐานการประเมิน LOQ ครบในตารางที่อ่าน ห้ามยืนยันว่าเป็น LOQ เพียงเพราะเป็นระดับต่ำสุด
13. หน้าสุดท้าย 24/23 และข้อความสรุปซ้ำ ต้องสร้างเลขหน้าและผลสรุปจากข้อมูลเดียวกัน

## แหล่งอ้างอิงสำหรับสูตร

- CIPAC 3807: https://www.cipac.org/images/pdf/validat.pdf (หัวข้อ 3.2.1 และ Appendix I: C เป็น decimal mass fraction)
- Eurachem Planning and Reporting Method Validation Studies (2025): https://eurachem.org/images/stories/Guides/pdf/MV_Guide_planning_supplement_2nd_ed_EN.pdf (การออกแบบ nested study และ ANOVA)

เกณฑ์ของสารอื่นต้องมาจาก protocol/SOP ที่เลือกโดยผู้ใช้ การคำนวณผ่านไม่ใช่การรับรองวิธีโดยอัตโนมัติ

## ความคืบหน้าที่มีหลักฐานตรวจแล้ว

- เพิ่มหน้า Precision ที่รับฐาน C แยกตามระดับและข้อมูลดิบรายวัน คำนวณ balanced ANOVA, Horwitz และ HorRat พร้อมปฏิเสธจำนวนซ้ำไม่เท่ากัน
- เพิ่ม Sample/QC แบบเลือกแนบรายงาน คำนวณ %w/w, %w/v โดยต้องมี density, Standard Recovery, Matrix Spike และ %Difference
- เพิ่มรายงาน HTML แบบ standalone พร้อมตัวอย่างใน iframe ที่ไม่อนุญาต script ตารางและ SVG กราฟสร้างจากข้อมูลเดียวกับหน้าเว็บ
- เพิ่มไฟล์งาน JSON รุ่น 1 บันทึกและเปิดกลับโดยตรวจ schema ก่อนเปลี่ยน state ไม่รับผลคำนวณที่ฝังมาในไฟล์เป็นผลจริง
- ทดสอบสูตร/รายงาน/ไฟล์งานรวม 15 ข้อผ่าน และ ESLint ของไฟล์ที่เกี่ยวข้องผ่าน
- ตรวจตัวอย่างรายงานบนหน้าเว็บแล้ว ยังต้อง QA รายงานที่กรอกครบและการพิมพ์หลายหน้า รวมถึงตารางบนมือถือ
- เพิ่มตารางกรอกแบบแยกช่องครบข้อมูลหลัก Precision และ QC; แถวผิดรูปแบบ/ช่องเกินไม่ถูกทิ้งเมื่อแก้ไข และแถว TSV ที่มีช่องว่างต้นท้ายถูกปฏิเสธอย่างถูกต้อง
- เพิ่ม Specificity: Blank รายครั้งแยก Solvent/Matrix, จำนวนซ้ำและเกณฑ์ RT/Area/Blank ที่ปรับได้, หลักฐานอ้างอิงและบันทึกผลทบทวน ผู้ทบทวนต้องกรอกผลและหลักฐานครบก่อนบันทึก
- ผลทบทวนผูกกับข้อมูลต้นทางแบบเรียงฟิลด์คงที่ เปลี่ยนผลวัด/เกณฑ์/หลักฐาน/ผู้ทบทวน/การเตรียมสารแล้วกลับเป็นรอตรวจสอบ ไฟล์งานเก่าที่ไม่มีข้อมูลนี้เปิดได้และเริ่มเป็นรอตรวจสอบ
- ตรวจบนเว็บด้วยข้อมูลจำลอง Standard 6 ครั้งและ Blank แต่ละชนิด 3 ครั้ง: ผ่าน 5 รายการหลังบันทึกทบทวน รายงานแสดงหลักฐาน/ผลตรงกัน เปลี่ยน Matrix Blank reference แล้วเหลือผ่าน 4 รายการและรอทบทวนใหม่
- เพิ่ม Stock หลายชุด (น้ำหนัก, Purity, ปริมาตร, Certificate/Lot, วันที่/ผู้เตรียม) และเลือก Stock ของแต่ละระดับ แสดง Stock/Actual ในรายงานและบันทึกใน JSON พร้อมตรวจรหัสซ้ำหรืออ้างอิง Stock ที่ไม่มีอยู่
- เพิ่มสร้างแถว Linearity/Accuracy จาก Actual เต็มทศนิยม โดยเว้น Area/Found ว่างและไม่ทับตารางที่มีข้อมูลแล้ว ตัวอย่าง Accuracy ที่เตรียมแยกกันยังต้องกรอก Actual จริงต่อรายการ
- Linearity ตรวจ Actual ของทุก Injection เทียบแผนด้วย tolerance ที่ระบุ ไม่ตัดสินผ่านจากจำนวนระดับอย่างเดียว ปรับจำนวนซ้ำ/R²/Area RSD ได้ ตารางสรุปในรายงานจัดกลุ่มด้วยเงื่อนไขเดียวกับหน้าเว็บ
- ตรวจบนเว็บด้วย Stock หลัก 54.25 mg / 92.7% / 25 mL และ Stock เพิ่มเติม 50 mg / 100% / 25 mL: สร้าง 15 แถวตามแหล่ง Stock, ทดสอบสมการจำลอง Area=250×Actual ได้ R²=1; เปลี่ยนน้ำหนัก Stock หลักแล้วเตือนเฉพาะ 12 แถวที่ใช้ Stock หลัก โดยเก็บผลวัดเดิม
- ทดสอบสูตร/ไฟล์งาน/รายงานที่เกี่ยวข้อง 30 ข้อผ่าน และ ESLint ผ่าน ไม่ได้ build หรือ push
- เพิ่ม Calibration หลายชุด: สมการ/Slope/Intercept/R²/ช่วงจากเครื่องพร้อมหลักฐาน หรือ OLS จากข้อมูลดิบอย่างน้อย 3 ความเข้มข้น เลือกสมการเฉพาะตัวอย่างและตรวจ R²/ช่วงก่อนส่งผล
- เพิ่มการเตรียมรายตัวอย่างและคำนวณ Found จาก Area สำหรับ Accuracy, Intermediate Precision, Sample, Standard QC และ Matrix Spike เลือก Stock/ปริมาตรเฉพาะรายการได้ และป้องกันการนับรหัสเตรียมซ้ำเป็นตัวอย่างอิสระ
- เปิดใช้ข้อมูลเชื่อมโยงแยกตามหัวข้อ ตารางผลที่คำนวณเป็น read-only; ข้อมูลกรอกตรงเดิมเก็บไว้ในไฟล์งานและคืนกลับเมื่อปิดโหมด หากมีแถวผิดจะไม่ส่งเฉพาะส่วนที่เหลือไปคำนวณ
- รายงานเพิ่มตารางตามรอยรหัสตัวอย่าง → Calibration/หลักฐาน → Area/Found และ Stock/ปิเปต/Actual พร้อมข้อมูลดิบ Calibration
- QA บนเว็บ: Area 126.3 กับ slope 250/intercept 1 ได้ Found 0.5012 mg/mL และ Stock 2.01159 × 250/1000 ได้ Actual 0.5028975; ปิดโหมดแล้วข้อมูลเดิม 0.5,0.5,0.49 กลับมา; Area 1000 นอกช่วงทำให้รอผลทั้ง Accuracy; ตรวจตัวอย่างรายงานแล้วตรงกัน
- ทดสอบรอบรวมก่อนเพิ่มกรณี round-trip/read-only/report ใหม่ผ่าน 39 ข้อ; รอบเจาะจงล่าสุดผ่าน 19 ข้อ และ ESLint ผ่าน ไม่พบข้อผิดพลาด TypeScript ในไฟล์ Validation (ทั้ง repository ยังมีข้อผิดพลาดเดิม)
- ยังเหลือข้อมูล Specificity รายพีค, หน่วยที่เลือกได้บน UI, การนำเข้า Excel/PDF โดยตรง และ QA รายงานครบทุกหัวข้อพร้อมพิมพ์หลายหน้า รวมถึงรายละเอียดตาม template ต้นฉบับ
