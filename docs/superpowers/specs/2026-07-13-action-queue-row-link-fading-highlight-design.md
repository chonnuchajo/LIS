# คลิกแถวใน "งานที่ต้องจัดการ" → ไฮไลท์ที่จางหายเอง

วันที่: 2026-07-13
สถานะ: อนุมัติแล้ว

## ปัญหา

การ์ด **"งานที่ต้องจัดการ"** (`ActionQueue`) บน Executive Dashboard ให้เข้าถึงคำขอได้ทางเดียวคือกดปุ่ม "ดู" เล็ก ๆ ท้ายแถว ทั้งที่ทั้งแถวคือคำขอใบเดียวกัน

ปลายทางคือ `/petitions?highlight=<id>` ซึ่งหน้ารายการจะเรนเดอร์ใบที่ไฮไลท์ไว้ใน **กรอบเหลืองแยกต่างหากเหนือลิสต์** พร้อมชิป "ไฮไลท์ N รายการจากแดชบอร์ด" และปุ่ม "ล้างไฮไลท์" ที่ต้องกดเอง กรอบนี้อยู่ค้างจนกว่าจะกดล้าง และดูเหมือนกล่องแปลกปลอมที่ไม่ใช่ส่วนหนึ่งของลิสต์

## เป้าหมาย

1. คลิกที่แถวคำขอในการ์ด "งานที่ต้องจัดการ" แล้วลิงก์ไปได้เลย ไม่ต้องเล็งปุ่ม
2. ไฮไลท์ในหน้ารายการทำหน้าที่ "ชี้เป้า" อย่างเดียว — เด่นอยู่ 5 วินาทีแล้วจางหายเอง เหลือการ์ดคำขอธรรมดา

## ข้อจำกัดที่กำหนดดีไซน์

`PetitionListPage` เป็น **server-paginated** — ใบที่คลิกมาจากแดชบอร์ดอาจอยู่หน้า 3 ของลิสต์ ถ้าไฮไลท์เฉย ๆ โดยไม่พาใบนั้นมาเรนเดอร์ ผู้ใช้จะไม่เห็นอะไรเลย กรอบเหลืองแยกที่มีอยู่ตอนนี้เกิดมาเพื่อแก้ปัญหานี้ ดีไซน์ใหม่จึงต้องยังคง fetch ใบที่ไฮไลท์ด้วย `GET /petitions?ids=` เหมือนเดิม เพียงแต่เปลี่ยนวิธีแสดงผล

ปุ่มไทล์ด้านบนแดชบอร์ด (`AlertStrip` — "เกินเวลา", "ผลผิดปกติ" ฯลฯ) ส่ง id มาทีละหลายใบ ดีไซน์ต้องรองรับทั้งใบเดียวและหลายใบ

## ดีไซน์

### 1. `src/components/dashboard/exec/ActionQueue.tsx`

- เลขคำขอในคอลัมน์แรกกลายเป็น `<Link to={highlightPath([u.petitionId])}>` — ลิงก์จริง เพื่อให้คีย์บอร์ด/screen-reader ใช้ได้ และคลิกขวาเปิดแท็บใหม่ได้
- ทั้ง `<tr>` มี `onClick` → `navigate(highlightPath([u.petitionId]))` ปลายทางเดียวกับลิงก์ พร้อม `cursor-pointer` และ hover เปลี่ยนพื้นหลัง
- ตัดคอลัมน์ปุ่ม "ดู" ทิ้ง เพราะซ้ำซ้อนกับการคลิกแถวแล้ว

### 2. `src/pages/PetitionListPage.tsx`

- **ลบ** กรอบเหลืองแยก + ชิป "ไฮไลท์ N รายการจากแดชบอร์ด" + ปุ่ม "ล้างไฮไลท์"
- ใบที่ไฮไลท์ (ผลจาก `?ids=` fetch เดิม กรองด้วย `applyVisibilityFilter` เดิม) ถูก **แทรกเป็นการ์ดปกติไว้บนสุดของลิสต์** ภายใน `Card` เดียวกับรายการคำร้อง และ **ตัดซ้ำ** กับใบที่บังเอิญอยู่ในหน้าปัจจุบัน (ใบเดียวกันต้องไม่เรนเดอร์สองครั้ง)
- เมื่อใบที่ไฮไลท์เรนเดอร์แล้ว → `scrollIntoView` ไปที่การ์ดใบแรก
- การ์ดที่ไฮไลท์มี ring/พื้นหลังสีเหลือง ควบคุมด้วย state `glowing` (เริ่ม `true`) → `setTimeout(5000)` ตั้งเป็น `false` → สีจางหายด้วย CSS transition เหลือการ์ดธรรมดา **ใบยังอยู่บนสุด ไม่หายไปไหน**
- `?highlight=` ยังคาอยู่ใน URL (ไม่แตะ history) แต่จะถูกล้างทันทีที่ผู้ใช้ค้นหา / เปลี่ยนตัวกรองสถานะ / เปลี่ยนหน้า — คือ `updateParams` ลบ `highlight` ออกเสมอ เว้นแต่ผู้เรียกส่งค่ามาเอง

### สิ่งที่ไม่เปลี่ยน

- `highlightPath()` ใน `src/lib/execSummary.ts`
- `GET /petitions?ids=` และตัวกรองสิทธิ์ `applyVisibilityFilter` — ใบที่ผู้ใช้ไม่มีสิทธิ์เห็นต้องยังถูกกรองทิ้ง แม้จะมาจากลิงก์ที่แชร์กันมา
