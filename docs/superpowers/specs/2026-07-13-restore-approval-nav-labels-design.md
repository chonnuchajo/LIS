# คืนชื่อเมนูอนุมัติผลใน Sidebar

## เป้าหมาย

คืนชื่อเมนู Sidebar ที่ถูกเปลี่ยนเมื่อ 13 กรกฎาคม 2026 ให้เป็นชื่อเดิม เพื่อให้สอดคล้องกับคำสั่งงานของผู้ใช้:

- `/qc-approval`: `ออก Final Result` เป็น `อนุมัติผล QC`
- `/lab-approval`: `ออกผล Lab` เป็น `อนุมัติผล Lab`

## ขอบเขต

แก้เฉพาะ `label` ของสองรายการใน `NAV_ITEMS` ภายใน `src/lib/navItems.ts` เท่านั้น

## สิ่งที่ไม่เปลี่ยน

- URL และ route
- สิทธิ์การเข้าถึง
- หัวข้อหน้า ปุ่ม และข้อความสถานะใน workflow
- การไฮไลต์เมนู ซึ่งยังอิง URL เดิม

## การตรวจสอบ

รัน TypeScript type check เพื่อยืนยันว่าไฟล์คอมไพล์ได้ และตรวจ diff ว่ามีการเปลี่ยนแปลงเฉพาะ label สองรายการตามขอบเขต
